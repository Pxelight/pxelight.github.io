# Dotfiles Configuration

A clean and minimal Linux desktop setup built around the Hyprland compositor.

## Overview

This repository contains configuration files (dotfiles) for the following applications:

* **Hyprland** (Wayland compositor)
* **Kitty** (Terminal emulator)
* **Fastfetch** (System information tool)
* **Spotify-player** (Spotify TUI client)
* **Rofi** (Application launcher)
* **SwayNC** (Notification center)
* **Waybar** (Status bar)
* **Wlogout** (Logout menu)

## Required Packages

Ensure the following packages and CLI utility tools are installed on your system before applying the configurations:

### Core Environment & Apps
* `hyprland`
* `kitty`
* `rofi-wayland` (or `rofi`)
* `swaync`
* `waybar`
* `wlogout`
* `spotify-player`

### Utilities & Eye Candy
* `pavucontrol`
* `fastfetch`
* `btop`
* `hyprlock`
* `tty-clock`
* `cava`
* `pipes.sh`

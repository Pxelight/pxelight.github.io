Manual installation

The whole install is one copy: the folders inside the archive go straight into ~/.config. Do the steps in order.

Copying overwrites files with the same name. Step 2 makes a backup so you can go back to your old setup.

  1. Step 1. Check your Hyprland version

    These configs are written in Lua, which needs Hyprland v0.56 or newer. Waybar is used for the top bar, so install it too if you do not have it.

    hyprland --version
sudo pacman -S --needed waybar

    If the version is older, update first: sudo pacman -Syu.

  2. Step 2. Back up your current config

    This copies your whole .config folder to a safe place.

    cp -r ~/.config ~/config-backup

  3. Step 3. Download and extract the archive

    Use the download button above, or fetch it from the terminal. Extract it to a temporary folder first so you can see what is inside.

    curl -L -o ~/Downloads/dotfiles.zip https://pxelight.github.io/dotfiles/assets/configs/dotfiles.zip
unzip ~/Downloads/dotfiles.zip -d /tmp/pxelight-dotfiles
ls /tmp/pxelight-dotfiles

    If unzip is missing: sudo pacman -S unzip.

  4. Step 4. Copy the files into ~/.config

    The ls output from step 3 should list config folders such as hypr and waybar. Copy their contents directly into ~/.config:

    cp -r /tmp/pxelight-dotfiles/. ~/.config/

    If ls showed only one wrapper folder (for example dotfiles) and the config folders are inside it, copy from inside that folder instead:

    cp -r /tmp/pxelight-dotfiles/dotfiles/. ~/.config/

    Prefer a file manager? Open your home folder, press Ctrl+H to show hidden folders, then drag the extracted folders into .config.

  5. Step 5. Check the result and make scripts runnable

    The folders must sit directly inside ~/.config, so you should see ~/.config/hypr, not ~/.config/dotfiles/hypr.

    ls ~/.config/hypr
find ~/.config -name "*.sh" -exec chmod +x {} +

  6. Step 6. Apply the config

    If you are already in a Hyprland session, reload it. A full log out and back in is the most reliable way to load everything.

    hyprctl reload
pkill waybar; waybar &

Troubleshooting

Hyprland shows config errors or starts with a blank screen

Print the errors Hyprland found in the config:

hyprctl configerrors

The most common cause is a Hyprland version older than v0.56, because the Lua config is not read by older releases. Run hyprland --version and update if needed.

Waybar is missing or looks wrong

Restart it and read its output for errors:

pkill waybar; waybar

If icons appear as empty boxes, a Nerd Font is missing. Install one, for example sudo pacman -S ttf-jetbrains-mono-nerd, then restart Waybar.

A keybind or script does nothing

Make sure the scripts are executable (step 5), and that any program a keybind launches is installed. Open the Lua files in ~/.config/hypr to see which commands each keybind runs.

I want my old setup back

Restore the backup from step 2. This puts your previous files back over the copied ones:

cp -r ~/config-backup/. ~/.config/

Files that only exist in the dotfiles (not in your backup) stay in place. Delete those folders by hand if you want a clean restore.

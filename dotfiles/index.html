Get the dotfiles

Pick whichever way feels comfortable. Both end in the same place: the config folders sit inside ~/.config. Nothing else in your ~/.config is touched: only the files that come with the dotfiles are added. They are backed up first, and one command undoes everything.

  • Arch Linux
  • Hyprland v0.56 or newer
  • 11 apps installed for you
  • One-command undo
Terminal: install

Open a terminal, press Copy, paste, and hit Enter. It asks for your password to install programs. Using fish? Type bash first, then paste.

bash <(cat <<'EOF'
set -e
BK=~/config-backup-$(date +%F-%H%M)
mkdir -p "$BK/old"

# 1. Install the programs (anything you already have is skipped)
OFFICIAL=""; AUR=""
for p in hyprland waybar kitty fastfetch btop swaync pavucontrol spotify-player wlogout nm-connection-editor unzip curl; do
  if pacman -T "$p" >/dev/null 2>&1; then continue
  elif pacman -Si "$p" >/dev/null 2>&1; then OFFICIAL="$OFFICIAL $p"
  else AUR="$AUR $p"; fi
done
# rofi: use the Wayland build if Arch still ships it separately
if ! pacman -T rofi >/dev/null 2>&1; then
  if pacman -Si rofi-wayland >/dev/null 2>&1; then OFFICIAL="$OFFICIAL rofi-wayland"; else OFFICIAL="$OFFICIAL rofi"; fi
fi
echo "$OFFICIAL $AUR" > "$BK/new-packages.txt"
if [ -n "$OFFICIAL" ]; then sudo pacman -S --needed $OFFICIAL; fi
if [ -n "$AUR" ]; then
  H=$(command -v yay || command -v paru || true)
  if [ -n "$H" ]; then "$H" -S --needed $AUR || echo "Warning: could not install$AUR. Install it yourself later."
  else echo "Install an AUR helper (yay or paru), then run: yay -S$AUR"; fi
fi

# 2. Download and extract the dotfiles
curl -fL -o /tmp/dotfiles.zip https://pxelight.github.io/dotfiles/assets/configs/dotfiles.zip
rm -rf /tmp/pxelight-dotfiles
unzip -q /tmp/dotfiles.zip -d /tmp/pxelight-dotfiles
SRC=/tmp/pxelight-dotfiles
if [ ! -d "$SRC/hypr" ] && [ "$(ls -A "$SRC" | wc -l)" = 1 ]; then SRC="$SRC/$(ls "$SRC")"; fi

# 3. Work out which files will be added or replaced
(cd "$SRC" && find . \( -type f -o -type l \) | sed 's|^\./||') > "$BK/installed-files.txt"
(cd "$SRC" && find . -mindepth 1 -type d | sed 's|^\./||') | while IFS= read -r d; do
  if [ ! -e ~/.config/"$d" ]; then echo "$d"; fi
done > "$BK/new-dirs.txt"

# 4. Back up only the files that would be replaced
while IFS= read -r f; do
  if [ -e ~/.config/"$f" ] || [ -L ~/.config/"$f" ]; then
    mkdir -p "$BK/old/$(dirname "$f")"
    cp -a ~/.config/"$f" "$BK/old/$f"
  fi
done < "$BK/installed-files.txt"

# 5. Copy file by file (everything else in ~/.config is left alone)
while IFS= read -r f; do
  mkdir -p ~/.config/"$(dirname "$f")"
  cp -a --remove-destination "$SRC/$f" ~/.config/"$f"
  case "$f" in *.sh) chmod +x ~/.config/"$f" ;; esac
done < "$BK/installed-files.txt"

if ! systemctl is-active --quiet NetworkManager 2>/dev/null; then
  echo "Note: NetworkManager is not running, so Advanced Network Configuration will show no connections. Your network setup was not changed."
fi
echo "Done! Backup saved in $BK. Log out and back in."
EOF
)

What the command does

  • Installs the programs below, including Advanced Network Configuration if your PC does not have it
  • Backs up only the files it is about to replace, never your other files
  • Downloads and extracts the archive to a temporary folder
  • Copies the dotfiles file by file into ~/.config, leaving everything else alone
  • Makes the dotfile scripts executable and keeps a list of what it did, for the undo

Your old setup is safe

Only files that come with the dotfiles are added or replaced, one by one. Any other file or folder in your ~/.config is never touched. Replaced files are copied to ~/config-backup-DATE first. The command stops right away if something fails, and the undo command puts everything back.

Download dotfiles.zip

The commands below are for bash or zsh. Using fish? Type bash first, then paste.

  1. 1

    Extract the zip

    Right-click the file and choose Extract here, or use the terminal:

    unzip ~/Downloads/dotfiles.zip -d ~/Downloads/dotfiles

    If the extracted folder holds just one folder inside it, open that one: it is the folder that contains hypr and waybar. The backup command in step 2 finds it for you.

  2. 2

    Back up what will be replaced

    This copies only the files that the dotfiles would overwrite. Your other files are not touched, and the undo command uses this backup.

(cd "$SRC" && find . \( -type f -o -type l \) | sed 's|^\./||') > "$BK/installed-files.txt"
(cd "$SRC" && find . -mindepth 1 -type d | sed 's|^\./||') | while IFS= read -r d; do
  if [ ! -e ~/.config/"$d" ]; then echo "$d"; fi
done > "$BK/new-dirs.txt"

# Back up only the files that would be replaced
while IFS= read -r f; do

    mkdir -p "$BK/old/$(dirname "$f")"
    cp -a ~/.config/"$f" "$BK/old/$f"
  fi
done < "$BK/installed-files.txt"

  3. 3

    Drag the folders into .config

    Open your home folder and press Ctrl+H to show hidden folders. Then move the extracted folders (hypr, waybar and the others) into .config.

    When your file manager asks, choose Merge (or "keep both folders"), never "replace the whole folder". That way your own files inside those folders stay.

    Correct

    ~/.config/ ├─ hypr/ └─ waybar/

    Wrong: one folder too deep

    ~/.config/ └─ dotfiles/ └─ hypr/
  4. 4

    Install the programs

    The setup needs these apps (the command skips any you already have), including Advanced Network Configuration (package nm-connection-editor). wlogout comes from the AUR, so it needs an AUR helper such as yay or paru; the command tells you if you have none.

    bash <(cat <<'EOF'
set -e
OFFICIAL=""; AUR=""
for p in hyprland waybar kitty fastfetch btop swaync pavucontrol spotify-player wlogout nm-connection-editor; do
  if pacman -T "$p" >/dev/null 2>&1; then continue
  elif pacman -Si "$p" >/dev/null 2>&1; then OFFICIAL="$OFFICIAL $p"
  else AUR="$AUR $p"; fi
done

if ! pacman -T rofi >/dev/null 2>&1; then
  if pacman -Si rofi-wayland >/dev/null 2>&1; then OFFICIAL="$OFFICIAL rofi-wayland"; else OFFICIAL="$OFFICIAL rofi"; fi
fi
if [ -n "$OFFICIAL" ]; then sudo pacman -S --needed $OFFICIAL; fi
if [ -n "$AUR" ]; then
  H=$(command -v yay || command -v paru || true)
  if [ -n "$H" ]; then "$H" -S --needed $AUR || echo "Warning: could not install$AUR. Install it yourself later."
  else echo "Install an AUR helper (yay or paru), then run: yay -S$AUR"; fi
fi
EOF

  5. 5

    Make the scripts runnable and log in again

    Run this once, then log out and back in. It only touches the scripts that came with the dotfiles, and it uses the backup from step 2 to know which ones they are:

    bash <(cat <<'EOF'
set -e
BK=""
for d in $(ls -dt ~/config-backup-* 2>/dev/null); do
  if [ -f "$d/installed-files.txt" ]; then BK="$d"; break; fi
done
[ -n "$BK" ] || { echo "No backup found (config-backup-*) in your home folder."; exit 1; }
while IFS= read -r f; do
  case "$f" in *.sh) chmod +x ~/.config/"$f" ;; esac
done < "$BK/installed-files.txt"
echo "Done. Log out and back in."
EOF
)

After installing

Logging out and back in is the most reliable way to load everything. Already inside Hyprland and want to skip that? Reload it instead:

hyprctl reload
pkill waybar; waybar &

Something looks off? See Troubleshooting.

Changed your mind? Undo everything

One command puts your files back the way they were before the install.

Terminal: undo

Paste this the same way (fish users: type bash first). It only touches the files listed in your backup.

bash <(cat <<'EOF'
set -e
# Uses your newest installer backup (config-backup-...) in your home folder
BK=""
for d in $(ls -dt ~/config-backup-* 2>/dev/null); do
  if [ -f "$d/installed-files.txt" ]; then BK="$d"; break; fi
done
[ -n "$BK" ] || { echo "No backup found (config-backup-*) in your home folder."; exit 1; }
echo "Restoring from: $BK"

# 1. Undo only the files the dotfiles added or replaced
while IFS= read -r f; do
  case "$f" in ""|/*|../*|*/../*) continue ;; esac
  if [ -e "$BK/old/$f" ] || [ -L "$BK/old/$f" ]; then
    mkdir -p ~/.config/"$(dirname "$f")"
    cp -a --remove-destination "$BK/old/$f" ~/.config/"$f"
  else
    rm -f ~/.config/"$f"
  fi
done < "$BK/installed-files.txt"
# Remove folders the dotfiles created, but only if they are empty now
if [ -f "$BK/new-dirs.txt" ]; then
  sort -r "$BK/new-dirs.txt" | while IFS= read -r d; do
    case "$d" in ""|/*|../*|*/../*) continue ;; esac
    rmdir ~/.config/"$d" 2>/dev/null || true
  done
fi

# 2. Optionally remove the programs the installer added
if [ -s "$BK/new-packages.txt" ]; then
  GONE=""
  for p in $(cat "$BK/new-packages.txt"); do
    if pacman -Qq "$p" >/dev/null 2>&1; then GONE="$GONE $p"; fi
  done
  if [ -n "$GONE" ]; then
    echo "The installer added these programs:$GONE"
    read -rp "Remove them too? [y/N] " A </dev/tty
    if [ "$A" = y ] || [ "$A" = Y ]; then sudo pacman -Rns $GONE; fi
  fi
fi
echo "All set. Log out and back in to finish."
EOF
)
  • Only undoes its own changesReplaced files come back from the backup and added files are removed. Anything else you have in ~/.config, including files you created after installing, is left alone.
  • Asks before removing programsAfter a quick install, it lists only the programs the installer added and waits for your yes. Nothing you had before is touched.
  • Finds the backup itselfIt uses your newest config-backup-... folder. It works for the manual method too, after the backup in step 2. Keep that folder until you are happy.

Troubleshooting

Hyprland shows config errors or starts with a blank screen

Print the errors Hyprland found in the config:

hyprctl configerrors

The most common cause is a Hyprland version older than v0.56, because the Lua config is not read by older releases. Run hyprland --version and update if needed.

Waybar is missing or looks wrong

Restart it and read its output for errors:

pkill waybar; waybar

If icons appear as empty boxes, a Nerd Font is missing. Install one, for example sudo pacman -S ttf-jetbrains-mono-nerd, then restart Waybar.

A keybind or script does nothing

Make sure the scripts are executable (the quick install does this for you; with the manual method, repeat step 5), and that any program a keybind launches is installed. Open the Lua files in ~/.config/hypr to see which commands each keybind runs.

I want my old setup back

Use the one-command undo script. It restores your backed-up files and, after a quick install, can remove the programs the installer added.
